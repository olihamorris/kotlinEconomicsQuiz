# Kotlin Economics Quiz

## Overview

This is a console quiz program written in Kotlin. It asks the student a series of Economics questions one at a time, checks each answer, keeps the score, and shows the final result. The questions are stored as Question objects (a Kotlin data class), and a Quiz class keeps the score and checks the answers.

I wrote this software to learn the Kotlin language by building something small and useful: variables with val and var, expressions, conditionals, loops, functions, classes, and data classes. As a teacher, I also want to build educational tools, and this quiz is a first step toward that.
